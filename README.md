# ÇaykurOBS - Student Information System

ÇaykurOBS, Çaykur bünyesinde geliştirilmiş web tabanlı bir Öğrenci ve Kurum Bilgi Yönetim Sistemi projesidir.

ÇaykurOBS is a web-based Student and Institutional Information Management System developed during an internship at Çaykur.

---

## 🚀 Özellikler / Features

### 🇹🇷 Türkçe
- **Kullanıcı Yönetimi:** Rol tabanlı yetkilendirme ve güvenli giriş/oturum yönetimi.
- **Veritabanı Mimarisi:** İlişkisel veritabanı (SQL) üzerinde sorgulama, CRUD (Ekleme, Güncelleme, Silme) işlemleri.
- **Web Arayüzü:** ASP.NET Core MVC yapısı kullanılarak geliştirilmiş dinamik ve duyarlı (responsive) kullanıcı arayüzü.

### 🇬🇧 English
- **User Management:** Role-based access control (RBAC) with secure authentication and session management.
- **Database Architecture:** Optimized relational database queries and full CRUD (Create, Read, Update, Delete) operations.
- **Web Interface:** Dynamic and responsive user interface developed using the ASP.NET Core MVC architecture.

---

## 🛠️ Kullanılan Teknolojiler / Tech Stack
- **Backend:** C#, ASP.NET Core MVC
- **Veritabanı / Database:** SQL / Entity Framework Core
- **Frontend:** HTML5, CSS3, Bootstrap, JavaScript
